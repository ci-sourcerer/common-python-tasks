# `poe push-image`

Push the Docker image for this project to the container registry.

**Category:** [`container-images`](../container-images.md)

**Tags:** `containers`, `packaging`, `release`

## Usage

```shell
poe push-image [--debug]
```

## Arguments

| Argument | Type | Description | Default |
| - | - | - | - |
| `--debug` | `boolean` | Push the debug image. | `false` |
