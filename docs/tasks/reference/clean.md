# `poe clean`

Clean up temporary files and directories.

**Category:** [`daily-development`](../daily-development.md)

**Tags:** `clean`, `common`

## Usage

```shell
poe clean [--dist-only]
```

## Arguments

| Argument | Type | Description | Default |
| - | - | - | - |
| `--dist-only` | `boolean` | Only clean the dist directory (and related build artifacts) | `false` |
